# ADR-001：Phase 1 契约基线与环境差异

状态：接受。日期：2026-09-23。

决策：按用户提供的执行蓝图先实现 Phase 1，不将此前 SQLite 演示版直接升级为“符合蓝图的 V0.1”。采用独立 `agent_runtime` 包、Pydantic v2 严格模型、七个 JSON Schema、纯状态转换和静态计划校验。Phase 1 不引入空壳 API、数据库、队列或 Sandbox 模块。

理由：蓝图明确要求先固定七个 Schema、状态与授权边界，再建立单 Agent 纵切。此前演示版的字段、可恢复语义和进程隔离与蓝图有实质差异。直接扩展会让已有运行记录与新合同的语义混杂。

环境差异：蓝图期望 Python 3.12+，构建主机目前仅提供 3.11.5。当前元数据允许 3.11+，测试在 3.11 上执行；在 Phase 2 前增加 3.12 的 CI 验证，然后可将最低版本上调。Pydantic 版本固定为 2.13.5，pytest 固定为 9.1.1，保证本阶段可复现。

安全决策：用户请求对象不含权限字段，合同的 `permissions` 由可信入口传入。计划校验仅覆盖已登记 L0/L1 工具，L2/L3 默认拒绝。Phase 1 不运行生成代码，不执行外部写入。状态函数返回新快照但不假称数据库原子性；Phase 2 必须实现条件更新与 Task/Run/Event 同事务提交。
